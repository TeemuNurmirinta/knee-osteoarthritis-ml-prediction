# The preprocessing workflow required to reproduce the study dataset from the raw OAI data consists of the following steps:

1. Obtain the raw OAI data
-Register for access to the Osteoarthritis Initiative (OAI) database and download the required SAS data files from the OAI repository.

2. Identify the required variables
-Use the OAI data dictionaries, feature guide, and the variables reported in Table 1 of the manuscript to identify the datasets and variables required for the analysis.

3. Extract and merge the variables
-Retrieve the selected variables from the downloaded SAS files and merge them using participant identifiers to create a unified dataset.

4. Apply participant exclusion criteria
-Remove participants who do not meet the study inclusion criteria according to the exclusion rules described in the manuscript.
-Exclude participants with missing data required for the analyses.

5. Generate knee joint dimension measurements
-Download the corresponding knee radiograph DICOM files from the OAI repository.
-Use the MATLAB script provided in this GitHub repository to automatically extract the knee joint dimension measurements used in the study.
-Add the generated measurements to the analysis dataset.

6. Construct the outcome variables
-Create the target labels from the Kellgren-Lawrence (KL) grades 8-year follow-up.
-Combine KL grades 0 and 1 into a single class.
-Combine KL grades 3 and 4 into a single class.
-Retain KL grade 2 as a separate class.

7. Save the processed dataset in the csv format in excel.
